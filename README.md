# 주간 (Weekly)

매주 화요일 부모님께 질문 하나를 보내고, 1년 뒤 52호를 양장본 한 권으로 엮어 드리는 구독 서비스.
부모님 이름이 붙어 "주간 김영자"처럼 세상에 하나뿐인 주간지가 됩니다.

- 한글 브랜드: **주간** / 영문 워드마크: **WEEKLY**
- 개인별 제호: 한글 "주간 홍용기", 영문 "YONGKEE WEEKLY", 연간 합본 "YONGKEE WEEKLY — 2026 COLLECTION"
- 로마자 표기가 필요한 자리(도메인, 코드)에서는 jugan을 씁니다.

폴더
- `site/` 랜딩 페이지 (정적 HTML, 빌드 없음)
- `docs/` 질문 설계, 판매 카피, 경쟁 서비스 분석
