# 주간 (Weekly) 서비스 구조

> 2026년 9월 기준. 지금까지 결정된 내용을 한 문서로 모았다. 미정인 항목은 "검토 중"으로 표시했다.

## 1. 한 줄 정의

매주 화요일 부모님께 카카오톡으로 질문 하나를 보내고, 1년 뒤 52호의 답을 양장본 한 권으로 엮어 드리는 구독 서비스. 부모님 이름이 붙어 "주간 김영자"라는 세상에 하나뿐인 주간지가 된다.

### 브랜드 규칙

| 항목 | 표기 |
| --- | --- |
| 한글 브랜드 | 주간 |
| 영문 워드마크 | WEEKLY |
| 개인별 제호 | 주간 홍용기 / YONGKEE WEEKLY |
| 연간 합본 | YONGKEE WEEKLY — 2026 COLLECTION |
| 로마자 표기 (도메인, 코드) | jugan |
| 매주 발송물의 단위 | 호 (1호 ~ 52호) |
| 1년 결과물 | 합본호 |

## 2. 사람과 역할

| 역할 | 누구 | 하는 일 |
| --- | --- | --- |
| 구매자 | 자녀 (30~50대) | 결제, 부모님 초대, 질문 추가, 사진 업로드, 원고 확인, 책 수령 |
| 화자 | 부모님 (60~80대) | 매주 질문에 글 또는 음성으로 답변 |
| 독자 | 형제자매, 손주 (최대 5명) | 답이 올 때마다 함께 읽기, 댓글로 기억 보태기 (검토 중) |
| 운영자 | 주간 | 발송, 전사, 편집, 조판, 인쇄, 배송, 문의 응대 |

핵심 설계: 관리 주체는 자녀다. 부모님은 답만 한다. 로그인, 앱 설치, 사진 업로드를 부모님께 요구하지 않는다.

## 3. 상품 구조

| 상품 | 화자 | 결과물 | 가격 | 출시 순서 |
| --- | --- | --- | --- | --- |
| 주간 (기본) | 부모님 1인 | 주간 김영자 합본호 1권 | 정가 189,000원, 사전 신청가 149,000원 | 1차 |
| 주간 둘 | 부모님과 자녀, 같은 질문 | 한 권에 마주 보는 페이지 | 249,000~279,000원 (검토 중) | 2차 |
| 주간 나 | 본인 | 주간 지은 합본호 | 99,000~129,000원, 음성 전사 없음 (검토 중) | 3차 |

부가 상품
- 추가 인쇄 권당 39,000원
- 두 번째 구독 20% 할인
- 상위 옵션 (검토 중): 컬러 사진, 2권, 자녀 편지 페이지

원칙
- 책 없는 저가 옵션은 만들지 않는다. 책이 이 서비스의 가치다.
- 자동 갱신 없음. 1년이 끝나면 "책 찍기 또는 1년 더"를 묻는다.
- 가격은 부가세 포함으로 표기한다.

## 4. 서비스 흐름

```
구매 → 초대 → [매주 사이클 × 52] → 원고 확인 → 인쇄 → 배송 → 이후
```

| 단계 | 언제 | 무엇 |
| --- | --- | --- |
| 구매 | 0일 | 자녀가 부모님 이름, 카카오톡 번호, 생신, 결혼기념일, 시작일을 입력하고 결제 |
| 초대 | 0~3일 | 자녀가 초대 메시지를 부모님께 보냄. 주간 채널이 첫 안내를 보냄 |
| 매주 사이클 | 1~52주 | 아래 5절 |
| 원고 확인 | 52주 후 1주 | 자녀가 원고 열람, 사진 선택, 오탈자 수정 요청 |
| 인쇄 | 이후 2~3주 | 조판, 인쇄, 제본 |
| 배송 | 마지막 질문 뒤 4주 안 | 양장본 도착 |
| 이후 | 상시 | 웹 아카이브 유지, 음성 재생, 추가 인쇄, 1년 더 할지 선택 |

## 5. 매주 사이클

| 요일 | 일 |
| --- | --- |
| 화요일 09:00 | 질문 카드 발송 (알림톡 또는 채널 메시지) |
| 화~금 | 부모님이 글 또는 음성 메시지로 답변 |
| 금요일 | 답이 없으면 리마인드 1회. 그래도 없으면 건너뜀 |
| 답변 도착 즉시 | 음성이면 글로 옮기고 말투를 살려 다듬음 → 자녀와 독자에게 공유 → "n호가 모였습니다" 안내 |

발송 요일은 첫 50가족의 답변율을 보고 바꿀 수 있다. 이름에 요일이 없으므로 자유롭다.

### 질문 카드 형식

```
주간 김영자 12호

어머니, 이번 주 질문입니다.

처음으로 내 돈을 벌었던 날을 기억하시나요?
무슨 일이었고, 그 돈으로 무엇을 하셨나요?

두세 줄이면 충분합니다.
글이 번거로우시면 음성 메시지로 말씀해 주셔도 됩니다.
```

## 6. 콘텐츠 구조

- 기본 질문 52개, 10부 구성. 감각에서 감정으로, 가벼움에서 무거움으로. `docs/parent-story-questions-and-landing-copy.md` 참고.
- 명절과 기념일(설, 어버이날, 추석, 생신, 결혼기념일)에는 대체 질문으로 교체.
- 자녀가 직접 쓴 질문을 끼워 넣을 수 있다. 이 기능이 선물 가치를 만든다.
- 답변 형식: 글, 음성 메시지, 전화 녹음(검토 중). 사진은 자녀가 업로드.
- 답변은 원문을 보존하고, 책에는 말투를 살린 가벼운 다듬기 판을 싣는다.
- 질문 문장은 우리 것만 쓴다. 타사 질문 모음은 편집 저작물이라 베끼지 않는다.

## 7. 결과물

### 책
- 양장 제본, 본문 200쪽 내외, 상한 300쪽
- 표지: 한글 제호 "주간 김영자", 영문 제호 "YOUNGJA WEEKLY — 2026 COLLECTION"
- 사진: 부모님 사진과 자녀가 고른 사진. 컬러는 상위 옵션 (검토 중)
- 각 호 제목 옆 QR 코드 → 그 호의 부모님 음성 재생
- 추가 인쇄 가능

### 웹 아카이브 (가족 전용)
- 52호 목록, 각 호의 글과 음성
- 형제자매 최대 5명 접근
- 전체 내려받기 (글, 사진, 음성 파일)

### 음성
- 음성 답변 원본을 보존해 순서대로 엮는다. 별도 녹음 요청 없이 1년치 목소리가 쌓인다.
- 부모님께 "목소리도 함께 남습니다"를 처음부터 알린다.
- 카카오톡 음성 메시지는 압축 음질이고 길이 제한이 있어 이어 붙이는 처리가 필요하다.

## 8. 운영 구조

### 1단계: 첫 50가족, 전부 수작업

| 기능 | 도구 |
| --- | --- |
| 발송 | 카카오톡 채널 (알림톡 템플릿 심사 1~2주, 사업자등록 필요) |
| 답변 수신 | 채널 1:1 채팅 |
| 전사 | 음성 인식 후 사람이 교정 |
| 원고 관리 | 구글 시트 (부모 ID, 호, 질문, 답변, 음성 파일, 사진) |
| 조판 | 템플릿 기반 수동 |
| 인쇄 | 소량 양장 제본 외주 2곳 견적, 견본 1권 선제작 |
| 판매 | 랜딩 페이지 + 스마트스토어 (통신판매업 신고 후) |
| 응대 | 운영자 직접. 상실 직후의 고객이 많으므로 답장 톤이 브랜드다 |

### 2단계: 자동화

- 전사와 다듬기를 AI로 처리하고 사람은 최종 검수만
- 원고에서 책 PDF 자동 생성
- 자녀용 원고 확인 화면
- 1건당 변동비를 11~12만 원에서 6~7만 원으로 낮추는 것이 목표

## 9. 시스템 구조 (2단계 이후)

```
[랜딩 · 결제]  →  [구독 관리]  →  [발송 스케줄러]  →  카카오톡 알림톡
                                        ↓
                              [답변 수집] ← 카카오톡 채널 (글 · 음성)
                                        ↓
                              [전사 · 다듬기] → [원고 저장소]
                                        ↓
                    [가족 아카이브 웹]   [책 조판 생성 (PDF)]   [관리자 화면]
                                                  ↓
                                            인쇄 · 배송
```

원칙
- 부모님 쪽 접점은 카카오톡 하나. 앱과 로그인 없음.
- 자녀 쪽 접점은 웹. 결제, 초대, 질문 추가, 사진, 원고 확인, 아카이브.
- 음성 원본은 지우지 않는다.
- 아이콘은 Lucide, 화면 카피는 한국어. `CLAUDE.md` 규칙을 따른다.

## 10. 데이터 모델 (초안)

| 개체 | 주요 항목 |
| --- | --- |
| 구독 | 상품, 시작일, 상태, 결제, 구매자 |
| 화자 | 이름, 호칭, 카카오톡 번호, 생신, 결혼기념일, 음성 보존 동의 |
| 독자 | 이름, 연락처, 화자와의 관계 (최대 5명) |
| 질문 | 본문, 부, 순서, 대체 규칙, 작성자(기본 또는 자녀) |
| 호 | 구독, 호수, 질문, 발송일, 리마인드 여부, 상태 |
| 답변 | 호, 형식(글 또는 음성), 원문, 다듬은 글, 음성 파일, 도착 시각 |
| 사진 | 호 또는 책 전체, 업로드한 사람, 인쇄 여부 |
| 책 | 구독, 사양, 원고 확정일, 인쇄 상태, 배송 |

## 11. 정책

- 개인정보: 고인 정보는 개인정보보호법 대상이 아니지만 유족과 구매자 정보는 대상. 처리방침과 약관 필수. 만 14세 미만 가입 제한.
- 음성: 보존과 재생을 처음부터 고지하고 동의를 받는다.
- 이야기 사용: 가족만 열람. 광고나 학습에 쓰지 않는다.
- 서비스 종료: 최소 6개월 전 공지, 전체 데이터 파일 제공. 이 약속이 브랜드 신뢰의 핵심이다.
- 답변 중단: 부모님이 답하기 어려워지면 그때까지의 이야기로 책을 만든다. 남은 기간은 환불하거나 다른 가족에게 이전.
- 사후 접근: 돌아가신 뒤 아카이브 관리 주체와 형제간 접근 규칙 필요 (검토 중). 사후 서비스로 이어지는 지점.
- 상표: "주간" 단독은 16류, 41류에서 식별력 부족으로 등록이 어렵다. 로고 결합 상표 출원, 도메인과 카카오톡 채널명 선점으로 방어.

## 12. 로드맵

| 단계 | 목표 | 내용 |
| --- | --- | --- |
| 0 | 검증 | 랜딩 페이지 사전 신청, 카카오톡 채널 개설, 견본 책 1권 |
| 1 | 첫 50가족 | 지인 10가족 무료 → 후기와 견본 확보 → 유료 전환. 전부 수작업 |

## 13. 지표

- 사전 신청 수, 신청에서 결제 전환율

- 음성 답변 비율
- 자녀 질문 추가 비율
- 1건당 변동비

- 후기와 추천 유입 비율
