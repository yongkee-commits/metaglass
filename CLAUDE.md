# Project rules

## Context
This repository holds the brand, site, and concept work for **주간 (Weekly)**, a Korean subscription that sends parents one question a week over KakaoTalk and binds the 52 answers into a hardcover book titled "주간 <parent name>". Naming rules: Korean brand is 주간, the English wordmark is WEEKLY, a personal edition is "주간 <name>" in Korean and "<NAME> WEEKLY" in English (annual volume: "<NAME> WEEKLY — <year> COLLECTION"). Use jugan only where romanization is required (domains, code identifiers). A memorial service may follow later. The landing page lives in `site/`, working documents in `docs/`.

## Design skills
- Load `apple-design` (`.claude/skills/apple-design`) whenever building or reviewing UI, motion, gestures, sheets, typography, or translucent surfaces.
- Load `emil-design-eng` for animation and UI polish decisions.

## Icons
- Every icon comes from Lucide (https://lucide.dev). Follow `.claude/skills/lucide-icons/SKILL.md`.
- No emoji as icons, no other icon libraries, no hand-drawn SVG glyphs.

## Language
- Write user-facing copy in Korean unless asked otherwise.
